# Node Express Application

A Node.js and Express.js application built to practice and implement core backend concepts, including routing, middleware, Pug templating, form handling, MongoDB integration, cookies, and sessions.

## 🚀 Features

- Express.js server
- GET and POST HTTP methods
- Express Router and route organization
- Route parameters and regular expressions
- Public and private middleware
- Pug template engine
- Static files with `public` and `images` directories
- HTML form handling
- Body parsing with Express
- MongoDB database integration
- Mongoose models
- Storing user data in MongoDB
- Cookies
- Session management
- Registration form
- Dynamic response messages with Pug

## 🛠️ Technologies

- Node.js
- Express.js 5
- Pug
- MongoDB
- Mongoose
- Express Session
- Cookie Parser
